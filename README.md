# Arcos Dourados

Projeto acadêmico de desenvolvimento de uma experiência digital inspirada no contexto do **McDonald's**, desenvolvido com foco em programação, sistemas de interface e experiência do usuário.

O projeto reúne diferentes sistemas em Unity, conectando navegação, perfil, personalização e apresentação de informações em uma experiência interativa.

## Tecnologias

- **Unity**
- **C#**
- **Unity UI**
- **TextMeshPro**
- **DOTween**
- **PlayerPrefs**

## Principais sistemas

- Sistema de login com diferentes tipos de usuário
- Navegação entre telas e cenas
- Sistema de perfil e gerenciamento de dados
- Persistência local de informações
- Seleção e persistência de avatar
- Cardápio com produtos e categorias
- Sistema de seleção de respostas
- Feedback visual e sonoro para interação
- Transições entre telas

Os produtos do cardápio são estruturados com `ScriptableObject`, enquanto gerenciadores independentes controlam dados, navegação e apresentação da interface. :contentReference[oaicite:3]{index=3} :contentReference[oaicite:4]{index=4}

## Destaques técnicos

O projeto aplica conceitos de programação orientada a objetos, componentes da Unity, gerenciamento de estado, persistência de dados e separação de responsabilidades entre sistemas.

A arquitetura utiliza gerenciadores persistentes, componentes especializados de UI e estruturas de dados independentes da apresentação visual. :contentReference[oaicite:5]{index=5} :contentReference[oaicite:6]{index=6}
